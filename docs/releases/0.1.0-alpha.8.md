# 0.1.0-alpha.8

0.1.0-alpha.8 は、仲介実行の CLI 起動を機械可読出力へ切り替え、CLI が申告する推定コストとトークン利用量を**申告値**として評価イベントへ記録する。
申告値の定義と扱いは DESIGN の「スコアカード」の節を正本とする。
0.1.0 としてリリースするまで、本実装と蓄積データは開発確認専用であり、実際の仕事への利用を前提としない。

## 実支出の調査結果

Issue #5 の調査により、対応する四つの CLI のいずれも、公式の機械可読出力で実際の金銭的支出を提供しないことを確認した。
Claude Code の `total_cost_usd` は公式ドキュメントが推定値（同梱価格表からのローカル計算）と明記する名目値であり、定額プランでは請求と無関係である。
Codex CLI、Gemini CLI、Antigravity CLI はトークン利用量だけを返し、金額のフィールドを持たない。
このため実支出は引き続き取得せず欠測として明示し、CLI の申告をそのまま写した申告値を実支出と区別して記録する。

## API 世代と移行

設定 API は `agent-dock/config/v1alpha4` のまま変更しない。
JSONL イベント形式は `agent-dock/events/v1alpha5` へ更新した。
`executed` の実支出 `cost` を金額を保持できる型（`measurement_observed` と同じ通貨と最小単位）へ変更し、申告値の `estimated_cost`、`usage`、取得失敗理由の `report_failure` を追加する非互換な変更である。
非対応世代の検出時の挙動（既定の対話コマンドだけが既定値 No の確認・退避を行い、`scorecard`、`judge`、`observe` は確認なしでエラー終了する）は 0.1.0-alpha.7 から変更しない。

## 申告値の記録

- `estimated_cost`: CLI 申告の推定コスト。通貨は USD に固定し、金額はマイクロ単位の整数で保持する。
  申告の十進表記を浮動小数点を経由せず整数演算で変換し、0.5 マイクロ単位は切り上げる。
  CLI が 0 を申告した場合は 0 として記録し、フィールド自体が無い場合だけ欠測とする。
  `total_cost_usd` キーが存在して数値でない場合（`null` を含む）は変換失敗として扱う。
- `usage`: トークン利用量。入力、出力、キャッシュ済み入力、推論の各トークン数を CLI 固有の項目名から共通名へ正規化し、提供されない項目は欠測とする。
- `report_failure`: 申告値を取得できなかった理由を、パース失敗、保持上限超過、モデル不一致で区別する。
  CLI が構造的に提供しない値（Claude 以外の推定コストなど）は失敗ではなく、理由なしの欠測とする。
- 直接実行の観測（`measurement_observed`）は変更しない。

この変更のため `serde_json` の `raw_value` feature を有効化した（依存 crate の追加はない）。

## 実行アダプタと表示

各 CLI をヘッドレス実行の機械可読出力で起動し、応答本文の提示と申告値の取得を両立する。

<!-- markdownlint-disable MD013 -->

| CLI | 起動形式 | 応答本文と申告値 |
| --- | --- | --- |
| Claude Code | `claude --print --output-format json [--model M] <args>`（プロンプトは標準入力） | 終了時の単一 JSON の `result` を表示。`total_cost_usd` と `usage` を申告値へ |
| Codex CLI | `codex exec --json [--model M] <args> -`（プロンプトは標準入力） | JSONL の `agent_message` を到着順に表示。`turn.completed` の `usage` を合算して申告値へ（推定コストなし） |
| Gemini CLI | `gemini --output-format json [--model M] <args> --prompt ""`（プロンプトは標準入力） | 終了時の単一 JSON の `response` を表示。`stats.models` が単一モデルで、プロファイルのモデル指定と矛盾しない場合だけ利用量を記録（推定コストなし） |
| Antigravity CLI | `agy --output-format json [--model M] <args> -p PROMPT` | 終了時の単一 JSON の `response` を表示。`usage` を申告値へ（推定コストなし） |

<!-- markdownlint-enable MD013 -->

- 標準エラーは従来どおり行単位で即時表示する。Test アダプタは機械可読出力を解析せず、申告値は常に欠測とする。
- 単一 JSON の CLI は標準出力を 1 MiB を上限に保持して終了時に解析する。上限を超えた場合は、保持済みの内容を生のまま表示へ流した後は再び保持へ戻らず、以降のすべての出力を素通しして、申告値を欠測にする。
  素通しは行単位を基本とし、改行が現れない場合も一定量ごとに送出して、解析用バッファと送出前バッファの保持量を有界に保つ。
- JSON を解釈できない、応答本文キーが無い場合は、生の標準出力を表示し、警告を出し、申告値を欠測にする。実行の成否には影響しない。
  JSON としては正常なエラー応答のうち、Claude Code の `is_error` を伴う応答だけは、本文キーが文字列として存在すればそれを表示し、無ければ生出力へ縮退したうえで、申告値は取得できた範囲で記録する。
  ほかの CLI で応答本文キーが無い場合は、上記のパース失敗の縮退に従う。
- 標準出力の表示は、端末制御文字（改行を除く）だけを可視な表現へ置き換え、バックスラッシュを含む印字可能な文字は変えない。
  この置き換えは Test アダプタを含むすべての CLI の標準出力の表示に適用する。
- キャンセルされた実行でも解析を試み、完結した JSON なら本文と申告値を取得する。
- Codex は応答本文と利用量・失敗以外の JSON 行（既知の進行イベントと未知の種別を含む）を無視し、`error` と `turn.failed` を警告として表示し、JSON として解釈できない行だけを生のまま表示する。
  一行が 1 MiB を超えた場合はその時点で解析をやめ、以降の出力を有界の素通しへ切り替えて、利用量を欠測にする。`turn.completed` が現れない場合の利用量は理由なしの欠測とする。利用量の合算が上限を超える場合、または不正な `turn.completed` を検出した場合は、部分値を残さず利用量全体を欠測にする。複数回の合算で一部のイベントに欠けた項目は、その項目の合計を欠測にする。
- 設定の追加引数では、各 CLI の `--output-format`（等号形式と Gemini の短縮形 `-o` を含む）と Codex の `--json` を新たに拒否する。
- 機械可読出力の各フィールド名は、公式仕様に基づく fixture で固定して確認した。CLI の版差で形式が変わった場合、申告値は欠測へ縮退する。

会話本文のうちイベントへ保存するのは従来どおりの範囲だけであり、機械可読出力のその他の項目（ツールの引数と出力など）は保存しない。

## スコアカードと助言

- スコアカードの表示は変更しない。申告値の表示は後続リリースで行う。
- 射影は `executed` の実支出（`cost`）が値を持つ場合に実支出軸へ反映するよう接続した。本リリースの実運用では実支出は常に欠測である。
- 申告値の有無は、三軸の値、助言の候補選定と根拠に影響しない。

# v0.0.3

v0.0.3 は、実行確認で No を選んだ場合に agent-dock を終了せず、直前のタスク内容を編集して再確認できるようにする。
v0.1.0 としてリリースするまで、本実装と蓄積データは開発確認専用であり、実際の仕事への利用を前提としない。

## 更新前の注意

初回起動前に、動作中の v0.0.2 の agent-dock をすべて終了する必要がある。
設定とイベントの `schema_version` は `0.0.3` となり、v0.0.2 の形式は移行しない。
異なる版の設定は同じディレクトリへ退避して既定設定へ置き換え、異なる版を含むイベントログはログ全体を退避して空の履歴から始める。

## 実行確認と再入力

`Run this task? [Y/n]` に `n` または `no` と答えると、直前のタスク内容を編集可能な初期値としてタスク入力へ戻る。
この時点ではエージェント CLI を起動せず、`task_received`、`assigned`、`executed`、`judged` のいずれのイベントも記録しない。

編集後はタグ、プロンプト本文を記録するかの確認、実行プロファイルを再入力する。
タスクの変更に応じて分類、記録範囲、実行先を見直せるようにするためである。
実行を承認した時点の新しいタスク ID と時刻で `task_received` を記録し、続けて同じタスク ID の `assigned` を追記してから、選択したエージェント CLI を起動する。
No と再入力を繰り返しても、未実行タスクのイベントは残らない。

再入力時に Ctrl-C または EOF を入力した場合は、エージェント CLI を起動せず終了する。

## v0.0.2 から維持する挙動

実行プロファイルとスコアカード、イベントの射影、受け入れ判定、確認用データの仕様は v0.0.2 から変更しない。
実支出は引き続き取得しない。

# 0.1.0-alpha.10

0.1.0-alpha.10 は、0.1.0-alpha.3 の「0.1.0 までに解消する事項」が定めた二つの約束を果たす。
実行時の CLI 版と実際に選ばれたモデルの観測を評価イベントへ加え、開発用の架空データ生成ツールを実データから隔離する。
あわせて、0.1.0 のリリース監査で確定した、安全なテストプロファイルの助言からの除外を行う。
0.1.0 としてリリースするまで、本実装と蓄積データは開発確認専用であり、実際の仕事への利用を前提としない。

## API 世代と移行

設定 API は `agent-dock/config/v1alpha4` のまま変更しない。
JSONL イベント形式は `agent-dock/events/v1alpha6` へ更新した。
`executed` へ観測した CLI 版と観測したモデルを加える非互換な変更である。
非対応世代の検出時の挙動（既定の対話コマンドだけが既定値 No の確認・退避を行い、`scorecard`、`judge`、`observe` は確認なしでエラー終了する）は変更しない。

## 実行時の CLI 版とモデルの観測

- 仲介実行の開始前に、解決済みの実行可能ファイルへ `--version` を渡して起動し、標準出力の最初の行（前後空白を除き、最大 256 バイト）を観測した CLI 版として `executed` へ記録する。
  5 秒のタイムアウト、起動失敗、非ゼロ終了、空出力、UTF-8 として不正な出力は欠測とし、取得の失敗は本体の実行を妨げない。Test アダプタでは取得しない。
  観測に要した時間は、所要時間の実測へ算入しない。
- 機械可読出力から観測できたモデル名を `executed` へ記録する。
  Claude Code は `modelUsage` のキー、Gemini CLI は `stats.models` のキーから取得する。
  Codex CLI と Antigravity CLI は現行の機械可読出力にモデル名が無いため欠測になる。
- どちらの観測もプロファイルの同一性、帰属、射影には使わず、監査用の記録にとどめる。

## 開発用ツールの隔離

`mise run sample` は対象イベントログのパスの明示指定を必須にし、既定の実運用イベントログのパスと一致する指定は拒否する。
架空データが実運用の記録へ混入する経路を閉じる。

## 助言からのテストプロファイルの除外

エージェントを起動しない安全なテストプロファイルを、助言の候補母集団から除外する。
実績が最良でも候補として提案しない。
判断保留時の番号選択の既定値は、テストプロファイル以外のプロファイルが存在する場合はその先頭になる（存在しない場合は従来どおり先頭のまま）。
選択一覧への表示と、ユーザーによる明示的な指名は従来どおり可能である。

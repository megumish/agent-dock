# 0.1.0-alpha.1

0.1.0-alpha.1 は、一つの指示を登録済みの実行プロファイルへ依頼する対話型 CLI を提供する。
対応 OS は macOS に限り、ほかの OS での動作は保証しない。

## 実装範囲

指示の入力、実行プロファイルの選択、ユーザーの明示承認、ヘッドレス実行、結果の表示を実装した。
評価イベントの記録、受け入れ判定、スコアカード、助言は実装していない。
したがって、このリリースだけでは 0.1.0 の循環または VISION の成功基準を達成しない。

## 実行プロファイル

実行プロファイルは、識別子、表示名、アダプタ種別、実行可能ファイル、モデル、追加引数から構成する。
設定は `~/Library/Application Support/agent-dock/config.toml` に TOML 形式で保存する。
設定 API は `agent-dock/config/v1alpha1` で識別する。

設定ファイルが存在しない場合だけ、ユーザーの承認を得て次の既定プロファイルを作成する。

1. Codex CLI
2. Claude Code
3. Gemini CLI
4. Antigravity CLI

一覧の先頭を選択時の既定値とするため、初期設定では Codex CLI が選ばれる。
非対応の設定 API を検出した場合は、検出値と期待値を示し、既定値 No で作り直すか一度だけ確認する。
Yes の場合は元のファイルを一意な名前で退避し、現在の既定設定へ置き換える。
No または割り込みの場合は設定を変更しない。
履歴訂正前の数値 `schema_version` を持つ設定は移行せず、非対応の設定として同じ確認と退避の対象にする。

プロファイルに実行可能ファイルのパスを指定しなければ、アダプタごとのコマンド名を `PATH` から探索する。
明示したパスは、そのファイルの実行可能性を確認する。
利用できないプロファイルは理由とともに選択肢から除外し、一つも利用できなければ実行を開始しない。

## アダプタ

各アダプタは、対象 CLI が提供する非対話実行の形式に合わせて指示を渡す。

<!-- markdownlint-disable MD013 -->

| CLI | コマンドの形式 | 指示の渡し方 |
| --- | --- | --- |
| Claude Code | `claude --print [--model MODEL] [ARGS]` | 標準入力 |
| Codex CLI | `codex exec [--model MODEL] [ARGS] -` | 標準入力 |
| Gemini CLI | `gemini [--model MODEL] [ARGS] --prompt ""` | 標準入力 |
| Antigravity CLI | `agy [--model MODEL] [ARGS] -p PROMPT` | コマンド引数 |

<!-- markdownlint-enable MD013 -->

Antigravity CLI の実行中は、指示がローカルのプロセス引数として観測される可能性がある。
非対話実行に必要な引数と競合する追加引数は、設定の読み込み時に拒否する。

## 対話と実行

指示の入力には行編集を使い、空の指示を受け付けない。
実行プロファイルを選ぶと、指示、プロファイル、アダプタ、モデル、作業ディレクトリ、追加引数を表示する。
ユーザーが確認した場合だけ CLI を起動する。
作業ディレクトリには、agent-dock を起動した現在のディレクトリを使う。

認証、作業ディレクトリの信頼、サンドボックス、ファイル操作の承認は、各 CLI の設定と権限機構を継承する。
agent-dock はこれらを事前検査または仲介せず、CLI が返した標準出力、標準エラー、終了状態を利用者へ示す。
標準出力と標準エラーは行単位で区別して表示し、CLI の終了コードを agent-dock の終了コードへ反映する。

ユーザーが実行中に割り込みを入力すると、その CLI が起動した子孫を含むプロセスグループへ終了を要求する。
終了要求から三秒以内に停止しなければ強制終了し、agent-dock は終了コード 130 を返す。

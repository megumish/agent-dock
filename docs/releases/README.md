# リリース文書

リリース文書は、各版で実装した範囲と運用上の挙動を記録する。
v0.0.x は開発確認版であり、最小のループが揃った最初の実用版を v0.1.0 としてリリースする。
プロジェクトの理念と設計は [VISION.md](../../VISION.md) と [DESIGN.md](../../DESIGN.md) を正とする。

- [v0.0.1](./v0.0.1.md)：実行とユーザーの受け入れ判定を評価イベントとして蓄積する。
- [v0.0.0](./v0.0.0.md)：指示した仕事を選択したエージェント CLI で安全に実行する入口を作る。

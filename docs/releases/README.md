# リリース文書

リリース文書は、各リリースで実装した範囲と運用上の挙動を記録する。
プロジェクトの理念と設計は [VISION.md](../../VISION.md) と [DESIGN.md](../../DESIGN.md) を正とする。

## リリース一覧

`0.1.0-alpha.N` はいずれも 0.1.0 を組み立てて検証する開発確認版であり、0.1.0 のリリースまでは実際の仕事への利用を前提としない版である。

- [0.1.0-alpha.10](./0.1.0-alpha.10.md)：実行時の CLI 版とモデルの観測を加え、開発用の架空データ生成を実データから隔離し、テストプロファイルを助言の候補から除外する。
- [0.1.0-alpha.9](./0.1.0-alpha.9.md)：記録済みの申告値を、実支出と区別してスコアカードで開示する。
- [0.1.0-alpha.8](./0.1.0-alpha.8.md)：CLI 起動を機械可読出力へ切り替え、CLI 申告の推定コストとトークン利用量を申告値として記録する。
- [0.1.0-alpha.7](./0.1.0-alpha.7.md)：スコアカードを根拠とする助言と判断保留を追加し、0.1.0 の循環の全要素を揃える。
- [0.1.0-alpha.6](./0.1.0-alpha.6.md)：Claude Code と Codex CLI の直接実行を観測し、仲介実行と同じ評価基盤へ取り込む。
- [0.1.0-alpha.5](./0.1.0-alpha.5.md)：文書体系を整理し、文書保守とリリース監査の手順を追加する。
- [0.1.0-alpha.4](./0.1.0-alpha.4.md)：タスク再編集と、過去の完走またはキャンセル実行への判定追記を追加する。
- [0.1.0-alpha.3](./0.1.0-alpha.3.md)：評価イベントを実行プロファイル別のスコアカードとして表示する。
- [0.1.0-alpha.2](./0.1.0-alpha.2.md)：実行とユーザーの受け入れ判定を評価イベントとして蓄積する。
- [0.1.0-alpha.1](./0.1.0-alpha.1.md)：指示した仕事を選択したエージェント CLI で安全に実行する入口を作る。

# 0.1.0-alpha.9

0.1.0-alpha.9 は、0.1.0-alpha.8 で記録した申告値をスコアカードで開示する。
申告値の定義と扱いは DESIGN の「スコアカード」の節を正本とする。
0.1.0 としてリリースするまで、本実装と蓄積データは開発確認専用であり、実際の仕事への利用を前提としない。

## API 世代

設定 API は `agent-dock/config/v1alpha4`、JSONL イベント形式は `agent-dock/events/v1alpha5` であり、0.1.0-alpha.8 から変更しない。
製品版の更新だけを理由に設定またはイベントを作り直す必要はない。

## 申告値の開示

スコアカードの区分ごとに、三軸の行の下へ一段深い字下げの一行を追加し、次を表示する。

- 申告値を持つ実行数と仲介実行の母数、申告値を持たない実行数
- 申告値を取得できなかった理由の理由別件数（パース失敗、保持上限超過、モデル不一致）。
  理由別件数は申告値なし件数の内訳ではなく独立の計数である（取得失敗と利用量の記録は併存しうる）。
- CLI 申告の推定コストの集計。単一通貨で合算できる場合は整数演算による金額と件数、通貨が混在する場合は合算不能、合計が上限を超える場合も飽和させず合算不能として示す。
- 申告値を持つ実行の直近性

行のラベルは、CLI 申告の開示であり実支出ではないことを明示する。
母数は仲介実行だけとし、直接実行の観測には申告値が存在しないため、仲介実行が無い区分は開示対象なしとして区別する。
この行は `scorecard` コマンドと、タスク実行時のプロファイル一覧の両方に表示する。
通貨などの文字列は端末制御文字をエスケープする。

## スコアカードと助言への非影響

申告値の開示は表示だけの変更であり、受入率、所要時間、実支出の三軸の計算と、助言の候補選定・根拠には影響しない。
